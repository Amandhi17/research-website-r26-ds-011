# Sahaya – R26-DS-011 Research Website

Website for the SLIIT IT4010 research project **"AI Based Emergency Call and SMS Triage System for Disaster Response in Sri Lankan Low Resource Local Languages"** (group R26-DS-011).

Plain HTML, CSS and JavaScript – no build step. Open `index.html`, or serve the folder:

```bash
python -m http.server 8000
```

- `index.html` – the single-page site
- `css/` – `style.css` (base) and `theme.css` (Sahaya theme)
- `js/main.js` – menu, milestones, contact form
- `assets/img/` – figures and team photos
- `docs/` – project documents and slides (PDF)
